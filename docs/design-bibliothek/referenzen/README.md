# Referenz-Screenshots (Stufe 1–5)

Interne Gestaltungsvorlage, **nur Vorlage, nichts übernehmen**: keine Texte, Bilder, Logos, Schriften, Farben in genau
dieser Verwendung, kein Code. Es gelten die Regeln in `../README.md`. Die Screenshots sind Urheberrecht der jeweiligen
Seiten und nur als Inspiration und zum Vergleich im Team da. Sie bleiben in diesem Ordner, im Kit wie im
Projekt-Repo, und kommen nie in den Build, die Vorschau, einen Report für Kunden oder an Kunden; keine ganzen Seiten
nachbauen.

Die ganzen Seiten sind teils aus Scroll-Aufnahmen zusammengesetzt; wiederholte Kopfzeilen sind kein Teil des Layouts.
Je Ordner fasst `bauplan.md` den Aufbau aus den vier Bildern zusammen; die Gestaltungswahl liest den Bauplan, der
bauer dazu `1280-erster-bildschirm`, `390-erster-bildschirm` und `1280-ganze-seite`.
